## はじめに

生成AI（LLM）をビジネスや個人プロジェクトに活用する際、最も大きな障壁の一つとなるのが**セキュリティとデータプライバシー**です。特に、社内マニュアルや顧客の個人情報、独自の開発ナレッジといった機密データをクラウド上のLLM API（OpenAI等）に送信することに対して、抵抗感を持つ企業やエンジニアは少なくありません。

この課題を根本的に解決する手法として注目されているのが、すべての処理をローカル環境（自身のPCや自社サーバー内）で完結させる**「完全ローカルRAG（Retrieval-Augmented Generation）」**です。

本記事では、ローカル環境でLLMを実行できるツール**Ollama**と、軽量なオープンソースのベクトルデータベース**ChromaDB**を組み合わせ、社内データを一切外部に出さずに動く高精度なAI検索システムを構築する手順を具体的に解説します。

## ローカルRAGの概要とコンポーネント

まず、今回使用する主要な用語とツールの基本概念を整理しましょう。

### 専門用語の解説
*   **RAG（Retrieval-Augmented Generation / 検索拡張生成）**: LLMに社内文書などの外部データをあらかじめ「検索できる状態」にして保持させ、質問を受け取った際に「関連する文書を検索（Retrieval）」してから「その文脈を基に回答を生成（Generation）」させる技術です。これにより、LLMの誤情報発信（ハルシネーション）を抑えることができます。
*   **Ollama**: MetaのLlama 3やGemmaなどのオープンソースLLMを、自身のローカル環境で簡単に実行・管理できるツールです。
*   **ChromaDB**: テキストを数値表現（ベクトル）に変換して保存し、類似度の高い情報を瞬時に検索できるようにするオープンソースの「ベクトルデータベース」です。

### アーキテクチャの基本構造

完全ローカルRAGの処理フローは非常にシンプルです。

1. **ドキュメント準備**: ローカルのテキストファイルやPDFを読み込む。
2. **ベクター化（Embedding）**: テキストをOllamaの埋め込みモデルを使ってベクトル表現に変換。
3. **DB保存**: 変換されたベクトルをChromaDBに保存。
4. **検索と回答生成**: ユーザーの質問に最も近い情報をChromaDBから検索し、その文脈をOllamaのLLMに渡して回答を生成する。

全工程において外部ネットワークとの通信を行わないため、**外部へのデータ流出リスクを回避**できます。

## 【実践】PythonによるローカルRAGの実装

それでは、実際のPythonコードを用いてローカルRAGシステムを作成しましょう。

### 事前準備

1. **Ollamaのインストールとモデルの準備**
   [Ollama公式サイト](https://ollama.com/)からOllamaをダウンロード・インストールしてください。ターミナル（コマンドプロンプト）で以下のコマンドを実行し、モデルをローカルに取得します。

```bash
# 生成用LLM（Llama 3.2など）をダウンロード
ollama pull llama3.2

# テキスト埋め込み用のEmbeddingモデルをダウンロード
ollama pull nomic-embed-text
```

2. **必要なPythonパッケージのインストール**

```bash
pip install chromadb ollama
```

### サンプル実装コード

以下は、社内ガイドラインなどのドキュメントを読み込ませ、それに基づいた質問応答を行う完全なPythonスクリプトです。そのままコピー＆ペーストして実行可能です。

```python
import chromadb
import ollama

# --------------------------------------------------
# 1. ローカル用埋め込み関数の定義
# --------------------------------------------------
class LocalOllamaEmbeddingFunction:
    """Ollamaのnomic-embed-textモデルを利用してテキストをベクトル化するカスタムクラス"""
    def __init__(self, model_name="nomic-embed-text"):
        self.model_name = model_name

    def __call__(self, input):
        # inputは文字列のリストとして渡される
        embeddings = []
        for text in input:
            # Ollama APIを呼び出してテキストのベクトル値を取得
            response = ollama.embeddings(model=self.model_name, prompt=text)
            embeddings.append(response["embedding"])
        return embeddings

# --------------------------------------------------
# 2. ChromaDBの初期化とコレクション構築
# --------------------------------------------------
# ローカルディスク上にデータを保持する永続化クライアントを作成
chroma_client = chromadb.PersistentClient(path="./my_local_rag_db")

# 埋め込み関数の準備
embedding_fn = LocalOllamaEmbeddingFunction()

# コレクション（テーブルに相当するもの）を取得または作成
collection = chroma_client.get_or_create_collection(
    name="company_rules",
    embedding_function=embedding_fn
)

# --------------------------------------------------
# 3. 社内データの登録（サンプルデータ）
# --------------------------------------------------
documents = [
    "リモートワークの申請は、実施希望日の3日前までにSlackの #remote-work チャンネルで行ってください。",
    "経費精算の締め日は毎月25日です。領収書の原本は月末までに経理部に提出する必要があります。",
    "社内のパスワードポリシーとして、12文字以上かつ英大文字・小文字・数字・記号を含める必要があります。"
]

# ユニークIDとともにデータベースへ保存
collection.add(
    documents=documents,
    ids=["doc1", "doc2", "doc3"]
)
print("社内データの登録が完了しました。")

# --------------------------------------------------
# 4. RAG検索＆回答生成処理
# --------------------------------------------------
def ask_local_rag(query_text: str):
    """ユーザーの質問に対してChromaDBから関連文書を検索し、Ollamaで回答を作成する関数"""
    print(f"\n質問: {query_text}")
    
    # 1. 類似度の高い関連文書をChromaDBから2件取得
    results = collection.query(
        query_texts=[query_text],
        n_results=2
    )
    
    retrieved_docs = results['documents'][0]
    context = "\n".join(retrieved_docs)
    
    print(f"--- 参照されたコンテキスト ---\n{context}\n------------------------------")

    # 2. LLMへのプロンプトを作成（コンテキストを注入）
    prompt = f"""以下の「提供情報」のみに基づいて、質問に簡潔かつ正確に答えてください。
提供情報に書かれていないことには答えないでください。

【提供情報】
{context}

【質問】
{query_text}
"""

    # 3. Ollamaを使ってローカルLLMで回答生成
    response = ollama.generate(
        model="llama3.2",
        prompt=prompt
    )
    
    return response["response"]

# --------------------------------------------------
# 5. 実行テスト
# --------------------------------------------------
if __name__ == "__main__":
    answer = ask_local_rag("リモートワークの手続きはいつまでにどうやってすればいい？")
    print(f"回答:\n{answer}")
```

## よくある質問（FAQ）

### Q1. GPUが載っていないノートPCでも動きますか？
**A. 動作は可能ですが、回答の生成速度が遅くなる可能性があります。**
OllamaはCPU環境（特にApple SiliconのMacや、最新のIntel/AMD CPU）でも最適化されて動くため、数Bパラメータ規模（`llama3.2` 3Bモデルなど）であれば実用的なスピードで動作します。大量のテキスト処理や高速レスポンスを求める場合は、NVIDIA製GPU（VRAM 8GB以上）の搭載機器をおすすめします。

### Q2. 日本語の検索精度（テキストのベクトル化）を向上させるコツは？
**A. 埋め込み（Embedding）モデルの選定とテキストの分割幅（Chunking）が重要です。**
多言語対応が得意な `bge-m3` モデルなどをOllama上で使用するか、テキストを短すぎず長すぎない適切な長さ（300文字〜500文字程度）に区切ってデータベースへ保存することで、検索精度が向上します。

### Q3. PDFファイルやExcelデータもそのまま読み込めますか？
**A. 前処理（テキスト抽出）を行えば可能です。**
Pythonの `pypdf` や `pandas` などのライブラリを用いてファイルをプレーンテキストに変換し、それをChromaDBに格納することで、PDFや表データに基づいたRAGシステムも構築できます。
