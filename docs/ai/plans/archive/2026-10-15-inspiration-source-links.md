# 生成情報に「インスピレーション元」リンクを追加

**Date**: 2026-10-15
**Backlog**: P5 #8 情報源の明示（トレンド側を同時カバー）

記事末尾「生成情報」セクションに、記事作成のインスピレーション元（トレンドデータ + e621投稿）への
外部リンクを追加する。URL はすべて `fetch_topics.py` 収集データ（`data/topics/latest.json`、
`data/character_features.json`）から Python 側で構築し、Gemini 出力に依存しない。

版権開示は正確にするため、参考キャラクターごとの「作品」行は各投稿自身の版権（正確）を表示し、
集計ベースの「人気版権」行は「プロンプトに使用」ラベル付きでプロンプトに注入された結合リスト
（`_merge_copyrights`）を明示する。各参考キャラクターに「元投稿」リンク（`e621.net/posts/{id}`）を追加。
