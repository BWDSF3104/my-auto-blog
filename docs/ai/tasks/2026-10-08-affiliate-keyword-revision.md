# アフィリエイトキーワード選定ロジックの見直し (2026-10-08)

**状態: 未着手（問題記録） (2026-10-08)**

## 問題

楽天API商品カード実装後のローカルテストで、キーワードが汎用的すぎたため**記事テーマと無関係な商品**が返される問題が判明した。

### 実際のマッチ例（2026-10-08 ローカルテスト）

| キーワード | 返された商品 | 問題点 |
|-----------|-------------|--------|
| ケモノ | 動物モチーフペンケース | 許容範囲 |
| ファンタジー | レディースパンプス（シューファンタジー） | 無関係（ブランド名由来） |
| SF | iPhoneガラスフィルム | 無関係（「SF」を略号として解釈） |
| 百合 | 浴衣福袋（百合の花柄） | 無関係（花の「百合」） |
| ケモノ ファンタジー | 化物語 DVD-BOX | 弱関連（「バケモノ」+「ファンタジー」） |
| ケモノ SF | ティッシュケース（SF-3521型番） | 無関係（型番由来） |
| ケモノ 百合 | 商品なし | - |

### 根本原因

1. **ジャンル単体キーワードが汎用的すぎる**: 「ファンタジー」「SF」「百合」は楽天市場では商品カテゴリとして広く使われるため、ケモノ記事の文脈とは無関係な商品がヒットする
2. **2語以上の組み合わせが型番・ブランド名と衝突する**: 「SF-3521」「シューファンタジー」のような型番・ブランド名に部分一致する
3. **記事の具体的な主題（例: アーctic hare anthro、cybernetic sparks）をキーワードに反映していない**: 現在は world_setting / relationship のみから生成しており、記事固有の要素が欠落

## 見直し候補

### 方向性A: キーワードの具体化
- ジャンル単体（「ファンタジー」「SF」）は**除外**し、必ず「ケモノ」複合で検索
- 記事の char_type / world_setting / relationship をより具体的に組み合わせ
- 例: 「ケモノ 獣人 ファンタジー」「ケモノ 百合 動物」

### 方向性B: Gemini生成商品名の活用
- `<!-- AFF_PRODUCT: "keyword" -->` プレースホルダー（比較表内）のキーワードを優先使用
- Geminiが記事文脈に基づいて商品名を生成するため、相対的に具体的
- 現在 `process_inline_products` で処理されているが、末尾セクションの `inject_affiliate_links` には反映されていない

### 方向性C: 検索結果の関連性フィルタ
- 楽天APIの返却商品名に記事の主要キーワード（char_type, world_setting）が含まれるかチェック
- 無関係と判定した商品はカードに含めない（フォールバック: 検索リンク方式）

### 方向性D: キーワード数の制限
- 現在は最大7kw（ケモノ1 + ジャンルN + 関係性1 + ケモノ+ジャンルN + ケモノ+関係性1）
- API呼び出しコスト・実行時間・無関係マッチのリスクを考慮し、上限を2-3kwに絞る
- 優先順位: Gemini商品名 > ケモノ+具体ジャンルの組み合わせ > 単体

## 影響範囲

- `scripts/generate_article.py`: `_kemono_affiliate_keywords` / `process_inline_products` / `inject_affiliate_links`
- 楽天API呼び出し回数と実行時間（1kwあたり1.5秒間隔）
- 記事のSEO・ユーザー体験（無関係な商品カードの表示はUX悪化）
