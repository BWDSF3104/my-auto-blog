# インラインコード禁止ルールの一般化

**Status**: 完了
**Date**: 2026-10-22
**Next Action**: AGENTS.md コマンド実行ルールの更新

## 意図 / 背景

既存ルール「インライン Python 禁止」は言語（Python）指定のため、エージェントはインライン PowerShell へ逸脱する。本来の意図は「コマンドラインに実行コードを埋め込む形」全般の禁止で、Kilo の許可コマンドリストが使い捨てインライン文字列で汚染されることを防ぐこと。

## 調査結果 / 変更内容

- 根因: ルールが言語指定のため禁止の意図（インライン全般）が伝わらない。
- 落としどころ: 境界を「どの言語か」ではなく「コマンドラインに実行コードが埋められているか」で定義。「コードが埋まったインライン」は言語を問わず禁止（`python -c`/`python -`/`powershell -c`/`-Command`/`node -e`/コードをパイプ等）、フラグ・パスのみコマンド（`git log`、`pytest`、`python -m pytest`等）は許可。代替手段は言語共通で `docs\ai\tmp\` へのファイル書き出し → ファイル実行。
- 変更: `AGENTS.md` の「## コマンド実行ルール」を「インライン Python 禁止」から「インラインコード実行禁止（言語無関係）」へ書き換え（境界・理由・代替手段の明記）。

## Verification

- 変更は `AGENTS.md`・`docs/ai/` のみ → pytest / build 不要（規約上の例外）。
- 変更箇所: `AGENTS.md` の「## コマンド実行ルール」（インライン Python 禁止 → インラインコード実行禁止（言語無関係））。
