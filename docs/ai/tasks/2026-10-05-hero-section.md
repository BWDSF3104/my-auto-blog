# ヒーローセクション実装

## 変更

- `src/components/Header.astro`: ヒーローセクションを追加
  - グラデーション背景 (`from-blue-600 to-indigo-700`、ダークモードは `from-slate-800 to-slate-900`)
  - キャッチコピー: 「AI がトレンドを収集し、自動で記事を書くブログ。」
  - ステータスバー: 記事数 / タグ数 / 最新更新日 (3カラムグリッド、レスポンシブ)
  - アクションボタン: 「最新記事を読む」「タグ一覧」
  - 統計情報は `import.meta.glob` でビルド時計算

## ビルド

- `npm run build`: 成功 (108ページ、2.87s)

## 影響

- `index.astro`: 変更なし（Header コンポーネントが包括的に変更）
- 既存のタイトル・サブタイトル・検索・ダークモードボタンは維持
