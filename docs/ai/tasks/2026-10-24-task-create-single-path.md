## 意図 / 背景

タスクファイル作成についてのルール記載を確認した結果、現行ルール（AGENTS.md / memory-bank-guide.md / slash コマンド）は「`task_manager.py add` を実行せよ」という**肯定的な指示のみ**で、write/edit ツールによるタスクファイル直接作成を禁止する**禁止条項**がない。そのために「task-add スクリプトを使わずにタスクファイルを作成してしまう」事例が生じた。

2026-10-26 ユーザー判断: 直接作成の**禁止条項ではなく、スクリプト使用を簡潔に明示する方向**に変更（詳細 `docs/ai/decisions/2026-10-26-task-create-script-usage-direction.md`）。
